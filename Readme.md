A modern full-stack video streaming platform, built using the MERN stack. Users can upload videos, watch content, interact with creators, manage channels, and engage through comments, likes, subscriptions, playlists, and more.

## 🚀 Live Demo

https://video-tube-fawn.vercel.app

# 🚀 Installation & Setup

## 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/VideoTube.git
```

```bash
cd VideoTube
```

---

## 2. Backend Setup

```bash
cd BackEnd
```

Install dependencies:

```bash
npm install
```

Run backend:

```bash
npm run dev
```

Backend runs on:

```bash
http://localhost:8000
```

---

## 3. Frontend Setup

Open a new terminal:

```bash
cd FrontEnd
```

Install dependencies:

```bash
npm install
```

Run frontend:

```bash
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# 🔗 API Integration

Update frontend environment variables:

```env
VITE_API_URL=http://localhost:8000
```

For production:

```env
VITE_API_URL=YOUR_RENDER_BACKEND_URL
```
